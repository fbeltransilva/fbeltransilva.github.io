# Francisco Beltran-Silva academic website

Static GitHub Pages website.

Main files:
- `index.html`
- `research.html`
- `teaching.html`
- `students.html`
- `personal.html`
- `cv.html`
- `contact.html`

Replace `assets/img/profile.jpg` with a real profile photo using the same file name.
Replace `assets/docs/cv.pdf` with the current CV using the same file name.
Add optional URLs in `assets/js/links.js`. Empty optional links are hidden from the public pages.
